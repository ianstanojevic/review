Ranked account analyzer for League of Legends. Download `Review-v1.1-windows.zip` below, unzip, run `Review.exe`.
Windows may warn that the file is unsigned: **More info → Run anyway.**

### New

- **Compare with your friends.** A new **Compare** tab: add up to five Riot IDs (or one click on a recent search) and see everyone side by side — radars on top of each other, the standings on overall score with where you place, and *"Best in the group at: Fighting, Farming… Lowest at: Survival"*.
- **Head to head.** Every skill and stat in one table — win rate, rank, KDA, CS/min, gold at 15, kill participation, damage share, vision, early deaths, first item. Teal is the best in the group, red the lowest; values that are equal as shown aren't coloured.
- **One fair scale for everyone.** Compare always scores all players against the same rank's players in their role. If *VS* is set to *My games*, it picks the highest rank benchmark you have, so a Gold and a Master friend can't both show 50.
- The players you add are remembered, and their games are fetched in the background while you keep using Review.
